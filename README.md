# AI Course Builder

An AI-powered course creation platform built with Next.js, React, PostgreSQL, and Google Gemini.

## Features

- Generate personalized courses based on topics and categories.
- Customize course difficulty and duration.
- Use AI to generate course content with Google Gemini.
- Authenticate users with Clerk.
- Store course data using PostgreSQL and Drizzle ORM.
- Track completed chapters and learning progress.
- Display relevant learning videos using the YouTube API.

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Authentication:** Clerk
- **Database:** PostgreSQL
- **ORM:** Drizzle ORM
- **AI:** Google Gemini API
- **Videos:** YouTube API

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env.local` file and add the required environment variables for Clerk, PostgreSQL, Google Gemini, and YouTube API.
4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.
